# Historian OS SKYNET Toolkit

Unified orchestration layer for validation, temporal analysis, spatial indexing, graph analysis and interoperable export.

## Quick start

- `make turbo` — validate + gaps + timeline + map + stats
- `make export-all` — interoperability exports
- `make dashboard` — local Command Center

The toolkit treats external/reference data as non-canonical until provenance and human review are satisfied.
