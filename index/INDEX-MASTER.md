# HISTORIAN OS SKYNET — INDEKS GŁÓWNY

> Centralny punkt nawigacyjny korpusu wiedzy.

## 1. Korpusy

- `HISTORIA` — historia powszechna i regionalna
- `SPORT` — motorsport, Formuła 1, endurance i inne dyscypliny
- `LOTNICTWO` — lotnictwo wojskowe i cywilne
- `TECHNIKA` — technologie, pojazdy, infrastruktura
- `KULTURA` — film, literatura, sztuka i media
- `BIOGRAFIE` — osoby i biogramy
- `MIEJSCA` — lokalizacje, obiekty i regiony
- `WYDARZENIA` — wydarzenia historyczne, sportowe i współczesne

## 2. Typy indeksów

| Indeks | Funkcja |
|---|---|
| Tematyczny | grupowanie według dziedziny i zagadnienia |
| Chronologiczny | oś czasu i zakresy dat |
| Osób | osoby, role i powiązania |
| Miejsc | lokalizacje i obiekty |
| Wydarzeń | wydarzenia oraz ich uczestnicy |
| Źródeł | bibliografia i materiały źródłowe |
| Relacji | połączenia między rekordami |

## 3. Standard identyfikatora

Każdy rekord używa identyfikatora zgodnego ze schematem `HOS-*`.

Przykład:

`HOS-F1-JOCHEN-RINDT`

## 4. Status opracowania

- `draft` — szkic
- `review` — weryfikacja
- `verified` — zweryfikowany
- `archived` — archiwalny

## 5. Zasada indeksowania

Nowy rekord powinien być możliwy do znalezienia co najmniej przez:

1. korpus,
2. kategorię,
3. tagi,
4. datę, jeśli występuje,
5. osoby/miejsca/wydarzenia powiązane,
6. źródła.

## 6. Następny etap

Uzupełniać indeks dopiero wraz z rzeczywistymi rekordami. Nie tworzyć fikcyjnych danych tylko po to, aby wypełnić strukturę.
